# How to Use the Generated ZIP Files

This guide explains the full setup process using the ZIP files generated by this project.

---

## Overview

The project generates two ZIP packages:

| ZIP | Contents |
|-----|----------|
| `all_sections.zip` | Student OU/account scripts, groups, and mapping |
| `teacher_scripts.zip` | Teacher OU/account scripts, groups, NFTS permissions, and drive mapping |

---

## Step 1 — Run the Student Scripts

Extract `all_sections.zip` and run the scripts on the **Domain Controller**:

1. Navigate to `all_sections/`
2. Run **`Run_all.bat`** — this creates:
   - The `students` OU and all section sub-OUs
   - All student accounts inside each section OU
   - The section security groups and the master `Students` group
3. Navigate to `group/`
4. Run **`groups.bat`** — creates the master `Students` group and adds all section groups

---

## Step 2 — Run the Teacher Scripts

Extract `teacher_scripts.zip` and run the scripts on the **Domain Controller**:

1. Navigate to `teacher/`
2. Run **`TeacherOU.bat`** — creates the `teachers` OU and all teacher accounts
3. Navigate to `group/`
4. Run **`groups.bat`** — creates the `Teachers` security group and adds all teachers
5. Navigate to `allNFTS/`
6. Run **`Run_all.bat`** — grants each teacher Modify (M) NTFS permission on their assigned section folders

---

## Step 3 — Create the Root Shared Folder

On the **File Server** (or Domain Controller), manually create the root semester folder:

1. Create the root folder (e.g. `26271stSem`)
2. Right-click → **Properties** → **Sharing** tab → **Advanced Sharing**
3. Enable sharing and set the **Share Permissions** to **Full Control** for:
   - `Administrators`
   - `Teachers` *(security group)*
   - `Students` *(security group)*
4. Click **OK** / **Apply**

> **Note:** Share permissions and NTFS permissions are separate.
> Share permissions control network access; NTFS permissions control what each user/group can do inside the folders.

---

## Step 4 — Run Student Mapping

Navigate to `mapping/` inside `all_sections.zip` and run on the **Domain Controller**:

1. Run **`mapping.bat`**
2. This script will:
   - Create a subfolder for each section under the root share
   - Create a personal subfolder for each student
   - Set NTFS permissions so each student can only access their own folder
   - Set each student's **home drive** (`H:`) in Active Directory — it will auto-map at login

---

## Step 5 — Deploy Teacher Drive Mapping (GPO)

Navigate to `allDrives/` inside `teacher_scripts.zip`:

1. **Copy** `{teacher}MultiDrive.bat` to the GPO Logon Scripts folder on the DC:
   ```
   \\domain\SysVol\domain\Policies\{GPO-GUID}\User\Scripts\Logon\
   ```
2. Open **Group Policy Management** (`gpmc.msc`)
3. Find your GPO → right-click → **Edit**
4. Navigate to:
   ```
   User Configuration → Windows Settings → Scripts (Logon/Logoff) → Logon
   ```
5. Click **Add** → **Browse** → select the `.bat` file → **OK**
6. On the **teacher's workstation**, run:
   ```cmd
   gpupdate /force
   ```
7. Log out and log back in as the teacher — all section drives will appear automatically

> **Important:** Copying the file to SYSVOL alone is not enough.
> You must register it in GPME so `scripts.ini` is created. Without this step the script will never run.

---

## Verification Commands

Run these on the teacher's or student's workstation to confirm everything is working:

```cmd
gpresult /r /scope user    # Check which GPOs are applied to the user
net use                    # List all currently mapped drives and their status
gpupdate /force            # Force refresh of Group Policy
```

---

## Full Setup Order (Quick Reference)

```
1. Run all_sections → Run_all.bat          (student accounts + groups)
2. Run teacher_scripts → TeacherOU.bat     (teacher accounts)
3. Run teacher_scripts → group\groups.bat  (Teachers security group)
4. Create root folder → set share permissions (Admins + Teachers + Students = Full Control)
5. Run all_sections → mapping\mapping.bat  (student folders + home drives)
6. Run teacher_scripts → allNFTS\Run_all.bat  (teacher NTFS permissions)
7. Deploy allDrives\.bat via GPME          (teacher multi-drive logon script)
```
